# 프로그래밍 기말 프로젝트

## 1. 프로젝트 소개
- **과목:** 컴퓨터프로그래밍
- **학번:** 202605024
- **이름:** 박성엽
- **수행 방식:** 개인 프로젝트
- **개발 언어:** C언어
- **개발 환경:** Visual Studio 2026

### 프로젝트 목적
C언어 수업에서 배운 변수, 조건문, 반복문, 배열, 함수를 활용하여 간단한 ATM 은행 관리 프로그램을 제작하였다.
사용자가 직접 입금과 출금을 진행하고, 현재 잔액과 거래 내역을 확인할 수 있도록 구현하였다.

## 2. 주요 기능

**① 입금**
- 사용자가 입력한 금액만큼 잔액이 증가한다.
- 0원 이하의 금액은 입금할 수 없다.

**② 출금**
- 사용자가 입력한 금액만큼 잔액이 감소한다.
- 현재 잔액보다 큰 금액은 출금할 수 없다.

**③ 잔액 조회**
- 현재 계좌에 남아 있는 금액을 출력한다.

**④ 거래 내역 조회**
- 배열을 이용하여 입금과 출금 기록을 저장한다.
- 저장된 거래 내역을 순서대로 출력한다.
- 최대 100건까지 거래 내역을 저장한다.

## 3. 사용한 C언어 문법
- **변수:** `int` 자료형으로 잔액과 입출금 금액 저장
- **입출력:** `printf()`, `scanf_s()`
- **조건문:** `if`, `else if`, `switch`
- **반복문:** `while`, `for`
- **배열:** `history[100]`
- **사용자 정의 함수:** `deposit()`, `withdraw()`, `showBalance()`, `showHistory()`

## 4. 프로그램 실행 방법
1. Visual Studio 2026에서 프로젝트를 연다.
2. C언어 소스 파일을 확인한다.
3. `Ctrl + F5`를 눌러 프로그램을 실행한다.
4. 메뉴에서 원하는 기능의 번호를 입력한다.
5. 종료하려면 0을 입력한다.

## 5. 실행 화면

프로그램 실행 시 다음과 같은 메뉴가 출력된다.

```text
===== ATM 은행 관리 =====
1. 입금
2. 출금
3. 잔액 조회
4. 거래 내역 조회
0. 종료
=========================
메뉴 선택:
```

실행 테스트에서는 10,000원을 입금한 후 3,000원을 출금하여 잔액이 7,000원으로 표시되는 것을 확인하였다. 잔액보다 큰 금액을 출금하려고 하면 잔액 부족 메시지가 출력되는 것도 확인하였다.

## 7. 개발 과정에서 어려웠던 점과 해결 방법

**한글 출력 오류**

프로그램을 처음 실행했을 때 콘솔 화면에서 한글이 깨지는 문제가 발생하였다.

이를 해결하기 위해 소스 파일의 인코딩과 컴파일러의 UTF-8 설정을 확인하고 수정하였다.

**입출금 오류 처리**

잔액보다 많은 금액을 출금하려고 할 때 출금되지 않도록 조건문을 사용하였다. 또한 0원 이하의 금액을 입력하면 안내 메시지가 출력되도록 구현하였다.
